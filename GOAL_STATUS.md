# Corporate Release Goal Status

Status convention: `0` = incomplete or unverified; `1` = proven by the listed
acceptance evidence. The progress percentage records independently verified
evidence toward the goal; it does not override the binary release status. No
release proceeds while any P0 goal is `0`.

## Required engineering loop

1. Product/SWE manager specifies the acceptance evidence and locks scope.
2. World-class SWE ships the smallest safe vertical change.
3. Controlling SWE independently reviews the diff and runs the failure/regression checks.
4. Product/SWE manager rechecks usability and acceptance evidence before any goal changes from `0` to `1`.
5. Repeat. If any check fails, keep the affected goal at `0` and fix it before release.

## Current external certification blockers

Production certification needs authorized access to Cloudflare Pages/Functions logs and deployments, Supabase schema/data and backups, GitHub Actions settings/secrets, and monitoring/analytics. Local code changes and tests do not substitute for that evidence.
